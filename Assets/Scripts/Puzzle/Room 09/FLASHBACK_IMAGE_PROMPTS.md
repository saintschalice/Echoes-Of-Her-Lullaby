## 🎨 GENERAL STYLE GUIDELINES

### **For ALL 4 Images**:

```
Style: Vintage 1970s photograph, sepia tone, grainy film quality
Mood: Dark, ominous, unsettling, psychological horror
Lighting: Dim, dramatic shadows, single light source
Color: Desaturated, sepia/brown tones, dark atmosphere
Quality: Slightly grainy, aged photograph look
Atmosphere: Tense, foreboding, disturbing but not graphic
```

### **Technical Specs**:
- **Aspect Ratio**: 4:3 or 1:1 (square) for UI display
- **Resolution**: At least 1024x1024 pixels
- **Format**: PNG with transparency (optional)
- **Style**: Realistic but stylized, not photorealistic

### **Avoid**:
- ❌ Too graphic/gory (keep it psychological horror)
- ❌ Modern elements (phones, modern clothes, etc.)
- ❌ Bright, cheerful colors
- ❌ Clear, happy faces
- ❌ Modern photography style

## 🛠️ AI TOOLS RECOMMENDED

### **Best AI Image Generators**:

1. **Midjourney** (Best quality, paid)
   - Use `/imagine` command
   - Add `--ar 1:1` for square format
   - Add `--style raw` for more realistic look

2. **DALL-E 3** (Good quality, via ChatGPT Plus)
   - Paste prompts directly
   - Can refine with follow-up requests

3. **Leonardo.ai** (Good, has free tier)
   - Use "PhotoReal" model
   - Adjust "Vintage" and "Horror" tags

4. **Stable Diffusion** (Free, local)
   - Use "Realistic Vision" or "Deliberate" model
   - Add negative prompts: "modern, bright, colorful, happy"

## 📝 USAGE IN UNITY

### **After Creating Images**:

1. **Import to Unity**:
   ```
   - Save as PNG files
   - Name: flashback_rope.png, flashback_pills.png, etc.
   - Import to: Assets/Art/Sprites/Room09/Flashbacks/
   ```

2. **Set Import Settings**:
   ```
   - Texture Type: Sprite (2D and UI)
   - Max Size: 1024 or 2048
   - Compression: High Quality
   ```

3. **Assign in Inspector**:
   ```
   - Select Mirror4_EvidenceSequence GameObject
   - In Inspector, find "Flashback Sprites" section
   - Drag each image to corresponding slot:
     - Flashback Rope → flashback_rope.png
     - Flashback Pills → flashback_pills.png
     - Flashback Knife → flashback_knife.png
     - Flashback Towel → flashback_towel.png
   ```

## 💡 TIPS FOR BEST RESULTS

### **When Using AI Generators**:

1. **Start Simple**: Try the "Close-up" or "Symbolic" versions first
2. **Iterate**: Generate multiple versions, pick the best
3. **Consistency**: Use same style keywords for all 4 images
4. **Test in Game**: Import and test how they look in the flashback panel
5. **Adjust**: If too dark/bright, adjust in Photoshop or Unity

### **If AI Results Aren't Good**:

1. **Use Photo Manipulation**:
   - Find stock photos of rope, pills, knife, towel
   - Apply sepia filter
   - Add grain/noise
   - Adjust lighting in Photoshop

2. **Commission an Artist**:
   - Show them these prompts as reference
   - Ask for 1970s horror aesthetic
   - Provide game context

3. **Use Placeholder Images**:
   - Start with simple symbolic images
   - Replace with better ones later
